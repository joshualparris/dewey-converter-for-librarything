Dewey Helper for LibraryThing

Upload your own LibraryThing export, find Dewey candidates from Open Library, review them, and export a clean working file.

Your catalogue stays on your device

The file is parsed in this browser. Only ISBNs are sent to the Open Library API when you press Find Dewey numbers. No LibraryThing password is needed or accepted.

1

Load your catalogue

In LibraryThing choose Export → Tab-Delimited Text or JSON. TSV is recommended.

4

Export your reviewed file

The original columns are kept and Dewey Helper columns are appended. Your source file is never overwritten.

This tool does not write back to LibraryThing because LibraryThing does not currently provide a supported member-book editing API.

How to use the result safely

  1. Prioritise rows marked High confidence, then review conflicting classifications.
  2. Check local cataloguing policy before replacing an existing call number.
  3. Use the exported file as a working list while editing LibraryThing manually.
  4. Keep your original LibraryThing export as a backup.
